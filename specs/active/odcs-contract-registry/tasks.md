# ODCS Contract Registry — Implementation Tasks

> **Phase 3 — Tasks.** Derived from `docs/spec.md` (v0.4.0) + `docs/design.md`. Ordered so dependencies are always satisfied. **Every implementation task `T-nn` has a paired test task `T-nna` immediately after it** (the paired-test rule). One task ≈ one Claude session. The spec is the oracle.
>
> **T-01…T-17** build the registry core (R-01…R-72). **T-18…T-26** build the Test Generator component (R-80…R-93, design §9). New test tier **`[gen-unit]`** — pure generator logic over catalog fixtures; the _generated_ tests are not executed (D-29).
>
> **Golden rule for implementation (Step 8):** write the failing tests first, get approval, then implement until green. If a test passes but contradicts the spec, the test is wrong.
